---

## How user answers

User must:
1. Fill the `**Answer:**` field for each question
2. Notify Reviewer when done (type `aegis` or "I answered the questions")

---

## How Reviewer processes answers

After user notification:
1. Read entire file
2. For each question with filled answer:
   - Update corresponding spec
   - Reclassify item per answer (🔴→🟢 or 🔴→🟡)
   - Mark question as `✅ Answered` above Answer field
3. For unanswered questions: keep as 🔴 in final report
4. Update `confidence-report.md` with new percentages
